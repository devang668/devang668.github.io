Copy a Web site to research

目前 GitHub 上最火、“粘贴网址就能把整个网站克隆成可运行 React 项目” 的开源方案，主要集中在下面 3 个仓库，按“傻瓜程度”与“可玩性”排序，给你一份直抄清单：

1️⃣ Open-Lovable（🔥 最火）

  • 一句话描述：输入任意网址 → 10 秒生成 React+Tailwind 源码，本地 npm run dev 就能跑。
  • 核心链路：Firecrawl 抓取 → GPT-4o/Claude/Gemini 生成代码 → E2B 沙盒自动启动。
  • GitHub：https://github.com/mendableai/open-lovable
  • 亮点
    • 支持 全栈（前端 + 可选 Node/Supabase 后端）。
    • 可选模型、可改 prompt，生成完直接在浏览器里二次编辑。
    • MIT 协议，可商用。
  • 注意
    • 需要自备 OpenAI / Anthropic / Google API key（抓取+生成两次调用，一次克隆约 ¥0.3-0.8）。
    • 国内网络需给 Firecrawl 配代理，否则抓站环节 404。

如果你想“先跑起来再改”，这是当下最省心的方案。

2️⃣ Screenshot-to-Code（📸 截图流派）

  • 一句话描述：上传一张网页截图 → 自动生成 HTML/React/Vue 代码，还能让 DALL·E 3 把缺失图片也补出来。
  • GitHub：https://github.com/abi/screenshot-to-code
  • 亮点
    • 不需要目标站点可访问，“看图写码”，对逆向敏感站很友好。
    • 支持 React + Tailwind / Vue + Tailwind / Bootstrap 多技术栈切换。
  • 注意
    • 只还原视觉层，交互逻辑、数据接口需要你自己补。
    • 同样需要 GPT-4V API key（一张图 ≈ ¥0.15）。

适合做“像素级临摹”或没有后端数据的静态页。

3️⃣ SiteCopy（🗂️ 传统整站镜像）

  • 一句话描述：经典 Python CLI，把整站 HTML/CSS/JS/ 图片甚至 MySQL 一起搬下来，适合“搬家”而非“改代码”。
  • GitHub：https://github.com/Threezh1/SiteCopy
  • 亮点
    • 递归下载 + 数据库导出 + 配置文件自动改写，一键平移服务器。
    • 不需要 AI key，纯本地流量。
  • 注意
    • 生成的是原样静态备份，不会给你 React 组件。
    • 仅适合 Linux / macOS，Windows 需 WSL。

想“原站整搬”或做灰度备份用它最稳。

✅ 30 秒选型建议

目的 直接选
快速拿到可改的 React 项目 Open-Lovable
只有设计稿 / 页面已挂 Screenshot-to-Code
整站迁移、不改技术栈 SiteCopy

🚀 本地 3 步跑起来（以 Open-Lovable 为例）

浏览器打开 http://localhost:5173，贴目标 URL → Generate，等 10 秒就能下载完整 React 项目。

克隆愉快，记得遵守对方版权、robots.txt 及相关法律，别把“学习副本”当成“上线盗版”。

曾仕强教授：“富不住大屋，穷不行远路”解读（基于视频核心观点整理）

大家好，今天和大家分享的是咱们传统国学里的一句智慧箴言——“富不住大屋，穷不行远路”。这句话听起来简单，背后却藏着对生活、对人性的深刻洞察，咱们一步步把它讲透。

先看前半句，“富不住大屋”。很多人觉得，有钱了就该住大房子，住豪宅，这才是“享福”，才配得上自己的财富。但从咱们传统文化的视角来看，这其实藏着几个需要警惕的地方。

第一，“大屋”往往意味着“大消耗”。不光是买房子的时候花钱多，后续的维护、打理、开销，都是一笔不小的数目。更重要的是，“大”有时候会让人“散”——心思散了，精力散了。比如原本专注于事业、专注于家庭的人，住进大屋之后，可能会把心思放在怎么装修、怎么炫耀、怎么维护面子上，反而忘了财富积累的初心，也忘了经营生活的根本。

第二，“大屋”容易招“是非”。咱们老祖宗常说“树大招风”，房子太大、太显眼，很容易引起别人的嫉妒，甚至招来不必要的麻烦。你过得好，别人看在眼里，有的是羡慕，有的可能就是“红眼病”，甚至会给你设绊子、传闲话。财富需要“藏”，需要“稳”，而不是靠“大屋”去张扬。真正的富足，是内心的安定，不是外在的排场。

第三，“大屋”可能让家人“离”。房子大了，空间隔得远了，家人之间的交流反而可能变少。以前住小房子，一家人挤在一块，吃饭、聊天、说说笑笑，感情很亲；住了大屋，各自待在自己的房间，少了那份“挤出来”的温情，反而容易生分。咱们追求财富，最终是为了家庭和睦，要是因为“大屋”丢了这份和睦，那就是本末倒置了。

再看后半句，“穷不行远路”。有人可能会说，“穷”更要去远方闯一闯，说不定能找到机会改变命运？这话有道理，但得有个前提——“行远路”需要成本，不光是钱，还有精力、风险，穷人往往“输不起”。

第一，“远路”的“经济成本”穷人扛不住。出门在外，吃、住、行哪样不要钱？穷人本身积蓄就少，一旦出门，要是找不到工作，或者遇到点意外，比如生病、丢东西，很容易陷入绝境。到时候不仅自己难，还可能连累家里人——本来家里就不宽裕，再寄钱给你应急，更是雪上加霜。咱们做事要“量力而行”，“穷”的时候，更该先把眼前的日子稳住，把能抓住的小机会做好，而不是盲目地“远走他乡”。

第二，“远路”的“风险成本”穷人耗不起。出门在外，陌生的环境、不熟悉的人，到处都是不确定性。你不知道会遇到什么人，会碰到什么事，要是走了弯路、受了骗，对穷人来说，可能就是“灭顶之灾”。比如有的人穷的时候想出门打工，结果被中介骗了钱，或者进了黑工厂，不仅没赚到钱，还受了罪，回来之后更难翻身。与其冒这么大的风险“行远路”，不如先在熟悉的地方积累经验、攒点本钱，等有了基础再做打算。

第三，“远路”可能让“责任”空了。穷人家里，往往更需要人扛起责任——比如照顾老人、陪伴孩子、帮衬家人。要是一味地“行远路”，把家里的担子扔给别人，就算最后赚了点钱，可能也补不回亲情的空缺，补不回对家人的亏欠。咱们传统文化里讲“孝”、讲“担当”，“穷”的时候，守住家人、守住当下的责任，比盲目追求远方的“机会”更重要。

其实不管是“富不住大屋”，还是“穷不行远路”，核心就一个——“务实”，就像咱们老祖宗讲的“中庸之道”。有钱了，别被“排场”迷了眼，要守住“稳”；没钱了，别被“幻想”冲了头，要守住“实”。生活不是比谁的房子大，也不是比谁走的路远，而是比谁能把日子过得踏实、安稳，比谁能守住内心的平和与家庭的和睦。

这就是老祖宗传下来的智慧，看着简单，真要做到，需要咱们多琢磨、多反思，把这些道理融进日常的生活里，才是真的懂了、真的用了。

注：以上文字稿基于视频标题及曾仕强教授一贯的国学讲学风格、核心观点整理而成，若需逐字逐句的完整内容，可参考原视频（链接：https://www.toutiao.com/video/7547499673343328806/）的字幕功能（视频播放器内通常可开启“字幕”选项），获取更精准的实时内容。
