你可以使用 Cloudflare Web Analytics 结合 UTM 参数来实现推广链接的追踪统计，从而了解不同位置的推广效果。具体方法如下：

启用 Cloudflare Web Analytics

  1. 登录 Cloudflare dashboard，选择你的账户。
  2. 点击 “Analytics & Logs” 下拉菜单，选择 “Web Analytics”。
  3. 点击 “Add a Site”，输入你的网站主机名，然后选择出现的消息框中的主机名并点击 “Done”。
  4. 如果你不想使用自动设置，可以展开 “Advanced Options”，选择 “Disable automatic setup”，然后复制提供的 JavaScript 代码片段。
  5. 将复制的 JavaScript 代码片段添加到你网站的 HTML 页面的</body>标签之前。

使用 UTM 参数标记推广链接

  1. 确定你要追踪的推广位置，例如不同的社交媒体平台、论坛、邮件等。

  2. 为每个推广位置的链接添加 UTM 参数。UTM 参数是添加到 URL 末尾的特殊参数，常见的参数包括：

    • utm_source：标识流量来源，如sina、wechat等。

    • utm_medium：标识广告媒介，如banner、social、email等。

    • utm_campaign：标识营销活动名称，如double11_sale、new_product_launch等。

    • utm_content

查看和分析数据

  1. 当用户点击带有 UTM 参数的推广链接访问你的网站后，Cloudflare Web Analytics 会收集相关数据。
  2. 你可以在 Cloudflare dashboard 的 “Web Analytics” 界面查看数据，通过分析不同来源、媒介和活动的流量数据，了解哪个位置的推广效果更好，比如哪个平台带来的点击量更多、用户停留时间更长等。

此外，你还可以结合 Google Analytics 等其他工具进行更详细的分析。如果你希望链接更简洁，也可以使用 Cloudflare Workers 创建自定义的短链接，并在短链接中嵌入 UTM 参数或其他追踪信息，同时利用 Workers Analytics 引擎来跟踪短链接的点击情况。
